## 2. 页面定位

- **给谁看**：想要「低成本、高收益」生活建议的普通读者。
- **核心任务**：让人能按主题、按证据等级、按「说人话」筛选，快速读到可执行建议，并能追溯来源。
- **产品特征**：单文件、可离线、明暗双主题、阅读位置记忆、收藏夹；信息密度高，但每条都给出成本 / 收益 / 证据。

## 4. 布局

- **顶栏**：`position: sticky`，`min-height: 56px`；品牌区 + 弹性空隙 + 搜索 300px + 跳转选择 + 按钮组，窄屏自动换行。
- **主体**：`.shell` 为 flex；左侧 `.toc` 固定 296px、`sticky` 于顶栏下、独立滚动；右侧 `main` 自适应，`max-width: 940px`，左右 40px。
- **章节**：`section` 下边距 44px；标题行 `h2` + 条数，下方 2px 分隔线。
- **条目**：单列卡片纵向排列；卡内「编号 + 标题」头部、徽标行、解释段、字段网格、来源折叠。
- **阅读进度**：注入到顶栏尾部，进度条为细长轨道。
- **断点**：≤ 1000px 侧栏隐藏，改用顶部章节跳转；≤ 760px 搜索框变窄、按钮组换行。

## 8. 交互与状态

- **密码门**：`?requirePassword=1` 时保留遮罩；校验成功后移除并恢复阅读；失败显示错误。
- **搜索**：对标题、说人话、字段、来源做全文匹配，命中词用 `<mark>` 高亮；无结果时显示空态提示。
- **筛选叠加**：搜索 + A 级 + 说人话 + 只看收藏可同时生效；筛选后触发 `life:filtered` 让进度重算。
- **阅读记忆**：滚动停止 700ms 后保存当前条目；`pagehide` 再存一次；下次进入显示「继续上次阅读」。
- **收藏**：`localStorage` 持久化；只认仍然存在的卡片 id。
- **无障碍**：`role="progressbar"` 带 `aria-valuenow`；收藏按钮带 `aria-pressed`；状态用 `role="status"` 播报；目录链接有 `title`。

## 11. 修改须知

- **单文件约束**：本页刻意零依赖、可离线；不要引入外部 CSS / JS / 字体 / 图片。
- **体积**：文件约 2.2 MB，编辑时避免整文件重排；只改目标段落。
- **数字一致性**：书名「34 节」、各节条数、条目编号必须与目录、跳转选项一致。
- **密码门**：只描述机制，不记录密码；它不是安全边界，敏感内容不要放进来。
- **必须同步**：本文件 + [`docs/change.md`](../../change.md) 的「高性价比人生指南」章节。
