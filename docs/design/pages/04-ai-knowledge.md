## 2. 页面定位

- **给谁看**：自己（工作中随时查）与同行（可复制提示词 / 规则）。
- **核心任务**：用搜索 + 主题筛选快速定位一条笔记，展开阅读，一键复制全文或复制全部代理规则。
- **内容结构**：6 个主题，共 35 条；其中代理规则 20 条是主体。

## 4. 布局

- **容器**：`.studio-wrap` `width: min(1200px, calc(100% - 64px))` 居中。
- **首屏**：`.knowledge-hero` 双栏 `1fr / 300px`，`gap: 72px`；封面卡右倾 3°、左侧 7px 墨绿书脊、硬阴影 `12px 12px 0 #dddcd3`，模拟一本手册。
- **工具条**：整宽卡片，内部两行：第一行「搜索 + 复制全部」，第二行「6 个筛选按钮」，第三行状态。
- **笔记区**：每个主题一个 `section`；标题行左侧 `h2` + 说明，右侧 `01 / 07 NOTES` 计数；下方 `.knowledge-grid` 三列卡片。
- **卡片**：`<details>` 结构，`summary` 内是标题 + 摘要 + 「阅读原文 ＋」，展开后显示正文。

## 8. 交互与状态

- **检索**：关键词按空格拆分，必须全部命中（标题 + 摘要 + 正文）；同时叠加主题筛选。
- **计数**：`#knowledgeCount` 实时更新；筛选按钮上的数字是静态总数，不随搜索变化。
- **复制全部**：只选 `data-rule="true"` 的卡片，按 `1. 2. 3.` 编号；没有规则时提示。
- **复制单条**：`plainText()` 去掉「复制全文」等按钮文字，保留正文。
- **空态**：无匹配时隐藏所有区块并显示空态卡。
- **无障碍**：`aria-pressed` 标选中分类、`aria-live` 播报数量、`summary` 原生可键盘展开。

## 11. 修改须知

- **关联文件**：`css/AI.css`、`script/AI.js`、`css/studio.css`。
- **数字必须一致**：首屏 35、筛选按钮 35 / 7 / 20 / 2 / 2 / 2、各区块 `01 / 07 NOTES`、复制按钮「20 条」——四处任一改动都要一起改。
- **代理规则**：只有 `data-rule="true"` 的卡片会被「复制全部」收录；新增规则卡记得加这个属性。
- **正文排版**：正文允许 `<br>`、`<strong>`、`<code>`；不要塞入脚本或外部资源。
- **必须同步**：本文件 + [`docs/change.md`](../../change.md) 的「小技能 · 知识手册」章节。
