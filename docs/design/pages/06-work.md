## 2. 页面定位

- **给谁看**：自己（下次遇到同样报错时直接查）与同事 / 接手者。
- **核心任务**：把「现象 → 原因 → 解决步骤 → 验证方式 → 撤销方式」写成可执行清单，命令能一键复制。
- **内容基调**：第一人称、克制、只写验证过的路径；不写「可能有用」的空话。

## 4. 布局

- **容器**：`.topbar` 与 `main` 分别 `width: min(1080px / 920px, calc(100% - 40px))` 居中（本页为内联样式，区别于其他工作台页的 1140px）。
- **顶栏**：flex 两端对齐，底部 1px 分隔线。
- **首屏**：`main` 顶部 60px 起，标题 `clamp(34px,6vw,58px)`，说明限宽 580px，下方计数行。
- **经验卡**：整宽 `<details>`，圆角 24px；`summary` 内「编号 + 标题 + 副题 + 标签」；展开后正文 28–34px 内边距。
- **步骤网格**：`.steps` 两列等宽，每格最小高 94px；窄屏单列。
- **命令块**：`.command` 独立卡片，标题行 + `<pre><code>` + 说明；验证区可再嵌套多个命令块。
- **导航条**：`.hub-links` flex 换行，胶囊链接。

## 8. 交互与状态

- **密码门**：首次进入需输入密码；成功后写入 `sessionStorage`，本次会话内刷新不再询问；`?requirePassword=1` 会清除登录态并强制验证。
- **展开状态**：`toggle` 事件把右上角标签从「点击展开」改为「已展开」。
- **复制按钮**：脚本为每个 `.command` 动态插入 `.copy-command`；复制内容为 `code.textContent`，不执行任何命令。
- **无障碍**：`summary` 原生键盘可操作；复制按钮带 `aria-label`；错误用 `aria-live` 播报。
- **空态**：无异步数据，无空态；命令块是静态内容。

## 11. 修改须知

- **关联文件**：`js/work-notes.js`、`script/studio.js`；样式在页面内联。
- **安全**：本页含命令与代理配置示例，禁止写入真实账号、令牌、内网地址；复制按钮只复制不执行。
- **密码门**：前端明文校验只是弱隔离，不构成安全边界；不要在页面里放真正的机密。
- **新增经验记得**：更新首屏「当前收录 N 条」。
- **必须同步**：本文件 + [`docs/change.md`](../../change.md) 的「工作经验库」章节。
