DOCUMENT STUDIO / 03

先立文档，再让 Agent 动手。

一套固定的 docs 目录 + AGENT.md：设计、任务、规范各就各位。选文件 → 复制骨架 → 贴给 AI，不用每次重讲一遍要求。

页面规模11–13 个位置只读 · 复制即用

STRUCTURE

先看目录长什么样

docs 放文档，AGENT.md 放在 docs 同级。页面 >5 时三个目录同构，≤5 时直接摊平成单文件。

    命名速查

    变更记录
    design / tasks / spec 各一份，只追加不修改
    技术栈规范
    docs/xxx编码规范.md，xxx 换成技术栈名
    归档
    docs/archive/日期-说明/，索引写 README.md
    根入口
    README.md 讲项目，AGENT.md 讲规则

    模板工作台

    左侧是文件位置，右侧是标题骨架。两个输入只替换 {项目名称} 与 {技术栈}，其余不用改。
